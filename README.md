# 拼豆图纸生成器 · Perler Bead Pattern Generator

把图片变成**真正能照着拼**的拼豆图纸。

上传一张图片，选好尺寸和色库，就能得到带色号、坐标和用量统计的图纸。自动生成后如果出现零碎杂色，还可以进入后期处理工作坊逐格修改，让成品更干净、更适合实际制作。

## 在线体验

**[立即打开在线版](https://sunner-wang-d8ght8niaaaea70b7-1467707525.tcloudbaseapp.com/perler/)**

## 为什么做这个？

普通像素化只能把图片变成格子，但拼豆还需要解决几个实际问题：颜色是否来自可买到的色库、每格到底用哪一种豆、总共要准备多少颗，以及自动匹配产生的少量杂色该怎么处理。

这个项目把“自动生成”和“人工精修”放进同一个流程：先快速得到完整图纸，再按自己的审美改掉局部不满意的颜色。

## 功能

### 图片生成图纸

- 支持 JPG、PNG、GIF 图片。
- 可设置目标宽度，兼顾小尺寸快速作品与大尺寸细节作品。
- 可选通用 A–H、Perler、Hama Midi、Artkal S 色库。
- RGB / CIELAB 两种颜色匹配方式，支持抖动、主色/平均采样。
- 支持亮度、对比度、饱和度、网格偏移等调整。
- 支持魔棒和自动角落背景移除。

### 后期处理工作坊

自动结果里有不需要的杂色？直接在图上修：

- 选择格子后，从**完整色库**中挑颜色替换；
- 单格改色、吸管取色；
- 复制 / 粘贴颜色和撤销修改；
- 一键替换整张图中同一种颜色；
- 预览可在 **50%–500%** 间缩放，配合滚动查看大图细节；
- 所有修改自动同步到用量表和导出文件。

### 制作辅助与导出

- 显示 / 隐藏基础网格、参考大网格、坐标和色号。
- 自动统计每种颜色的颗数，方便配豆与采购。
- 导出带坐标、色号和颜色用量表的 **PDF 图纸**。
- 导出 **PNG 预览图**，方便保存或分享。
- 导出**切片图**，将大尺寸作品分区制作。

## 小图还是大图？

小尺寸适合快速完成、小摆件或先试图；主体明确时，约 60 格左右的图也能保留表情和轮廓。

大尺寸更适合保留人物五官、发丝、动物毛色和细腻的明暗层次。遇到局部细节时，可以放大预览后再逐格修色。

## 自己部署 / 使用

这是一个纯前端项目：图片直接在浏览器中处理，不需要后端或数据库。

### 直接使用在线版

打开 [CloudBase 在线版](https://sunner-wang-d8ght8niaaaea70b7-1467707525.tcloudbaseapp.com/perler/) 即可使用。

### 下载后本地打开

下载仓库 ZIP 或克隆项目后，直接用现代浏览器打开 `index.html`：

```bash
git clone https://github.com/sunjx3316-cell/perler-pattern-generator.git
```

### 打包为一个便携文件

电脑安装 Python 后，在项目目录运行：

```bash
py -3 build_dist.py
```

会生成 `dist.html`。它内置界面样式、色库和核心逻辑，适合备份或分享给朋友。

> PDF 导出和页面样式目前使用公共 CDN 资源；如需在完全断网环境稳定使用，可将对应第三方资源下载后内置。
